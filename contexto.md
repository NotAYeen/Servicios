## 5. Proyectos Destacados

### Proyecto 01 — DESIGN FORGE
- **Descripción:** Suite de diseño y accesibilidad con estándares de contraste estricto bajo el estándar internacional WCAG 2.1, simulación en tiempo real de daltonismo (deuteranopia, protanopia, tritanopia) y exportación de Design Tokens.
- **Tecnologías / Tags:** React 19, Design Systems, WCAG 2.1 A11Y, Color Science
- **Enlace:** https://notayeen.github.io/designforge/
- **Imagen:** assets/project-designforge.webp

### Proyecto 02 — SQLEARN
- **Descripción:** Simulador interactivo retro para dominar SQL ejecutando un motor SQLite real directamente en el navegador mediante WebAssembly (sql.js). Incluye 25 misiones técnicas, persistencia virtual en memoria, validación sintáctica en tiempo real y arquitectura 100% serverless sin latencia.
- **Tecnologías / Tags:** SQLite WASM, WebAssembly, Client-Side Execution, Gamification
- **Enlace:** https://notayeen.github.io/SQLEARN/
- **Imagen:** assets/project-sqlearn.webp

### Proyecto 03 — WA VISUALIZER
- **Descripción:** Aplicación analítica de alta privacidad (Zero-Telemetry) para inspeccionar y correlacionar estadísticamente conversaciones exportadas de WhatsApp (.txt). Procesamiento 100% local con motor de expresiones regulares, nubes interactivas de términos y renderizado optimizado de miles de mensajes.
- **Tecnologías / Tags:** Data Privacy, Regex Engine, Data Visualization, Client-Side
- **Enlace:** https://notayeen.github.io/whatsapp-chat-visualizer/
- **Imagen:** assets/project-whatsapp.webp

### Proyecto 04 — DELPHINUS
- **Descripción:** Plataforma móvil y de gestión para la administración de inventarios, generación dinámica de catálogos y automatización operativa comercial. Diseñada con arquitectura modular, sincronización eficiente de datos y controles ergonómicos adaptados al ritmo del negocio.
- **Tecnologías / Tags:** Flutter, Android, Python, Software Architecture
- **Enlace:** https://github.com/NotAYeen/delphinus
- **Imagen:** assets/project-appmoda.webp
